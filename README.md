# Pixel Adventure

Небольшой 2D pixel-art прототип игры, реализованный на HTML5 Canvas.

🌐 **Live demo:** https://t80060869s.github.io/pixel-adventure/

![Image alt](https://github.com/t80060869s/pixel-adventure/raw/main/img/game.jpg)

## Общее описание
Игрок управляет персонажем на тайловой карте, исследует уровень и собирает предметы.  
Цель — очистить карту от всех предметов.

## Управление
- Стрелки — перемещение персонажа
- Кнопка «Начать заново» — перезапуск уровня с новой генерацией карты

## Игровые механики
- Тайловая карта размером 40×30
- Камера, отображающая часть карты и следующая за игроком
- Коллизии со стенами
- Сбор предметов с раздельным подсчётом:
  - 🟡 монеты
  - 💎 алмазы
- Пошаговая анимация персонажа при движении

## Условие победы
Уровень считается пройденным, когда на карте не остаётся предметов.

После выполнения условия:
- управление блокируется
- отображается поздравительный экран
- игроку предлагается начать новую игру

## Архитектурные решения
- Отрисовка мира с учётом камеры (viewport)
- Поведение объектов определяется типами тайлов
- Простая модель состояния без избыточных паттернов
- Код ориентирован на дальнейшее расширение (враги, цели, новые предметы)

## Запуск проекта
Открыть файл `index.html` в любом современном браузере.
